[1macme-cli[0m [38;5;246m1.4.0[0m
Ship static folders to Acme hosting

[1m[38;5;110mUSAGE[0m
  acme-cli [38;5;246m<command>[0m [38;5;246m[options][0m
  acme-cli deploy [38;5;246m<dir>[0m [38;5;246m[--force][0m

  Every command reads acme.json from the current folder when it exists; the
  flags below override it.

[1m[38;5;110mCOMMANDS[0m
  [1mdeploy [0m[38;5;246m<dir>[0m            Upload a folder and publish it
  [1mlogin[0m                   Store an API token for later commands
  [1mrollback [0m[38;5;246m<deployment-id…>[0m
                          Restore one or more earlier deployments and make the
                          latest of them live

[1m[38;5;110mARGUMENTS[0m
  [38;5;246m<dir>[0m                   Folder to upload

[1m[38;5;110mOPTIONS[0m
  [1m-p, --project [0m[38;5;246m<id>[0m      Project to act on [38;5;246m(default: from acme.json)[0m
  [1m-f, --force[0m             Skip the confirmation prompt
      [1m--dry-run[0m           Show what would be uploaded without sending anything
      [1m--region [0m[38;5;246m<name>[0m     Data centre to deploy to [38;5;246m(default: eu-west)[0m

[1m[38;5;110mEXAMPLES[0m
  [38;5;246m# Publish the build folder[0m
  [38;5;246m$[0m acme-cli deploy dist

  [38;5;246m$[0m acme-cli rollback d_8f2c

[1m[38;5;110mENVIRONMENT[0m
  [1mACME_TOKEN[0m              API token, used when no login is stored
  [1mACME_CONFIG_DIRECTORY_OVERRIDE[0m
                          Where tokens are kept
